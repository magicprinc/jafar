# OpenCode и другие клиенты: профилирование по запросу

Установленный skill `java-performance` работает через локальный терминал. Если клиент не подхватывает skills, передайте ему полный путь к `~/.agents/skills/java-performance/SKILL.md` и нужный reference. Для команд используйте [локальные рецепты](local-analysis.md) и [экспертный launcher](expert-tools.md). Ни контекст MCP-инструментов, ни persistent `java.exe` для этого не нужны.

- DSH web: опциональная регистрация `mcp-jafar` уже выключена; не включайте её ради анализа.
- OpenCode и другие профили имеют свои конфигурации. Их фактическое состояние не следует из DSH. Не редактируйте конфиг другого клиента и не останавливайте чужой JVM автоматически. Если владелец отдельно попросил отключить резидентный Jafar, сначала убедитесь, что этот клиент может выполнить практический сценарий через локальный launcher, затем выключите только его запись `jafar` штатным способом. Конфиг и официальный JAR сохраните для обратимости.
- Для запуска нужны уже установленные Python, JDK 25 и официальный Jafar. jvmlens и MAT выбираются по типу задачи. Не используйте JBang, сборку из `wip` или legacy `jafar show` как автоматический fallback: возможна установка плагина из сети и нестрогий JSON. Уточните проблему и используйте документированный локальный обход.
